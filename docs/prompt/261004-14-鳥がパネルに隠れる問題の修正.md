# 261004-14 鳥がパネルに隠れる問題の修正

**相談日**: 2026年10月4日

## プロンプト本文

```text
ゲームがうごくようにしてください
```

## 回答内容（または対応内容）

- 公開中のGitHub Pagesとリポジトリのindex.htmlが同一であること、JavaScriptに構文エラーがなく、ヘッドレスChromiumで卵→孵化→お世話→時間経過→産卵まで実行時エラーなく動くことを確認した。
- 実際の原因はレイアウトだった。卵・鳥・木・池・巣が画面下部に配置されており、スマホではお世話パネルの裏に完全に隠れていたため「鳥がいない」「動かない」ように見えていた。
- 鳥と背景小物を新しい「地面エリア」(#field)の中に配置し、JavaScriptでパネルを避けるよう地面の位置と地平線の高さを毎回計算するようにした（画面回転・リサイズにも追従）。
  - スマホ・タブレット（幅900px未満）：パネルは下、地面はその上の見える範囲。
  - PC：お世話パネルを左上、家族パネルを右上に置き、その間の地面で鳥が歩く。
- PCで家族パネルの鳥アイコンが巨大化していた問題を44pxに固定して修正した。
- 「＋3時間」ボタンがパネル外に見切れていたので、ごはん・あそぶ・ねると同じ列に移動した。
- スマホ用にパネルの余白・文字サイズを詰めた。
- iPhone 13 / iPhone SE / タブレット / PC の各画面サイズで、鳥がパネルに隠れずに見えること、全ボタンが画面内にあることをスクリーンショットで確認した。
