# 261004-11 鳥不在と音声起動の再修正

**相談日**: 2026年10月4日

## プロンプト本文

```text
ベルを押しても音が出ません。また鳥がいないです。新しい鳥が一羽もいません。
```

## 回答内容（または対応内容）

- 壊れた、または旧形式のlocalStorageセーブデータを読み込んでもゲーム全体が停止しないよう、各鳥データを正規化する処理を追加した。
- ID、種類、年齢、孵化状態、各ステータス、座標などに不正値があった場合に安全な値へ補正するようにした。
- 生存している鳥が0羽の場合は、既存データを消さずに新しいヒナを1羽追加し、必ずゲームを再開できるようにした。
- 選択中の鳥が死亡・欠損している場合は、生存している鳥を自動選択するようにした。
- 個別のSVG描画でエラーが起きても、その鳥だけ絵文字表示にフォールバックし、世界全体を停止させないようにした。
- 音声開始ボタンを押した直後に、明瞭な2音のテスト音を鳴らしてから鳥の鳴き声を鳴らす方式へ変更した。
- AudioContextがrunningにならない場合は「音を再試行」と表示するようにした。
