# 261004-23 飛行時に地面から空へ上がる

**相談日**: 2026年10月4日

## プロンプト本文

```text
飛ぶときは、ちゃんと空へ飛んでください
```

## 対応内容

- 成鳥の飛行高度を画面の地平線と鳥の位置から計算し、地面から空まで飛ぶよう修正。
- 鳥と足元のラベルを一緒に移動し、羽ばたいてから約1.8秒で地面へ着地。
- スマートフォン・PCで鳥が地平線より上に移動し、画面内に表示されることをテスト。

## 反映済みアクション

- js/ui.js、style.css、tests/game.spec.js、docs/REQUIREMENTS.md を更新。
- npm run format と npm test を実行し、main にコミット・push。
