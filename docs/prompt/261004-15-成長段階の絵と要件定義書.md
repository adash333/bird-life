## 回答内容（または対応内容）

- 鳥のSVGを成長段階ごとに描き分けた。
  - ヒナ：割れた卵の殻に入った小さく丸い鳥。頭にふわ毛、大きな目、淡い体色。
  - 若鳥：成鳥より一回り小さい体、小さな羽1本、短いしっぽ。
  - 成鳥：一番大きい体、3本の冠羽、長いしっぽ。
- 世界の中の各鳥の足元に「卵／ヒナ／若鳥／成鳥」のラベルを段階別の色で表示するようにした。
- 家族パネルのアイコンも同じ絵で段階が分かる。
- docs/prompt/ の01〜14の記録と現在の実装から `docs/REQUIREMENTS.md`（要件定義書）を作成した。各要件に根拠のプロンプト番号を付けた。
- 今後も要件定義書を更新するよう、AGENTS.md と save-prompt スキルの手順に「仕様が変わったら要件定義書を更新する」ルールを追加した。README から要件定義書へリンクした。
- ヘッドレスChromium（スマホ・PC）で3段階の絵とラベルが表示され、エラーが出ないことを確認した。
