# 261004-22 ゲームデータのJSONエクスポートとインポート

**相談日**: 2026年10月4日

## プロンプト本文

```text
ゲームデータをJSON形式でエクスポートしてまたインポートできるようにしてください。
```

## 対応内容

- お世話パネルにJSONエクスポート・インポートボタンを追加。
- 群れ、親子関係、名前、色・模様、成長、ステータス、睡眠・復活、選択、位置、お世話回数をJSONで保存・復元。
- インポート前に形式と値を検証し、不正なデータでは現在のゲームと保存を維持。
- インポートで現在のデータが置き換わることを操作欄に表示。
- エクスポートした実ファイルの再インポート、再読み込み、同じファイルの再利用、不正ファイルの拒否をスマートフォン・PCでテスト。

## 反映済みアクション

- index.html、style.css、js/save.js、js/main.js、tests/game.spec.js を更新。
- docs/REQUIREMENTS.md の保存要件と最終更新を変更。
- npm run format と npm test を実行し、main にコミット・push。
