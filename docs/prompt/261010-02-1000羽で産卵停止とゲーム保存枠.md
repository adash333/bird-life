# 261010-02 1000羽で産卵停止とゲーム保存枠

**相談日**: 2026年10月10日

## プロンプト本文

```text
生になってそれ以上生まないようにしてください。そして新しい同じゲーム保存されて作れるようにしてください。
```

```text
１０００羽 になったら。
```

```text
はい、別の保存枠を作る
```

## 対応内容

- 「1000羽になったらそれ以上産まない」という補足に従い、生きている家族（卵・寝ている鳥も含む）が1000羽になったら産卵を停止する。
- 1000羽未満では、元気な成鳥が繰り返し産卵する仕様を継続。
- 「新しいゲーム」で現在のゲームを保存したまま、卵1個から始まる別の保存枠を作成。「保存したゲーム」一覧から切り替えられる。
- 各ゲームの家族・ステータス・選択中の鳥・お世話回数などを独立保存。再読み込み時に最後に選んだゲームを復元。
- 既存の単一セーブはゲーム1として引き継ぐ。JSONの入出力は選択中のゲームを対象とする。
- 新規保存に失敗した場合は現在のゲームを維持してメッセージを表示する。
- スマホ・PCの全44テストが成功。
