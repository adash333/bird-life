# 261010-03 3回の時間経過で成鳥に成長

**相談日**: 2026年10月10日

## プロンプト本文

```text
プラス3時間ボタンを3回押すと、大人に成長させてください
```

## 対応内容

- 孵化直後の生後6時間から「＋3時間」を3回押すと生後15時間で成鳥になるよう成長条件を変更。
- 生後12時間未満はヒナ、12〜14時間は若鳥、15時間以上は成鳥。お世話による時間経過も同じ条件を適用する。
- 3回のボタン操作で成長し、成鳥の姿・サイズが再読み込み後も維持されることをスマホ・PCで確認。
- 飛行テストも新しい成長段階の境界に合わせて更新。

## 反映済みアクション

- js/birds.js、tests/game.spec.js、index.html、docs/REQUIREMENTS.mdを更新。
- npm run format、npm testを実行し、mainにコミット・push。
