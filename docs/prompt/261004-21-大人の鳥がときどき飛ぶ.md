# 261004-21 大人の鳥がときどき飛ぶ

**相談日**: 2026年10月4日

## プロンプト本文

```text
大人の鳥はたまに飛んでください。
```

## 対応内容

- 起きている成鳥が移動時に25%の確率で飛ぶよう変更。
- 羽ばたきながら45px浮かび、約1.8秒で着地するアニメーションを追加。
- 卵・ヒナ・若鳥・寝ている鳥は飛ばない。
- スマートフォン・PCのテストで飛行、羽ばたき、浮上、着地、通常の歩行を確認。

- js/ui.js、js/birdArt.js、style.css、tests/game.spec.js を更新。
- docs/REQUIREMENTS.md に飛行要件を追記し、最終更新を変更。
